# Capa Officer

Senior CAPA Officer specialist for managing Corrective and Preventive Actions within Quality Management Systems. Provides CAPA process management, root cause analysis, effectiveness verification, and continuous improvement coordination. Use for CAPA investigations, corrective action planning, preventive action implementation, and CAPA system optimization.

## Overview

This repository preserves the skill definition published in the AITMPL catalog and its available companion resources.

## Installation

Clone this repository into your Claude Code personal skills directory:

```bash
git clone https://github.com/Brajesh31/claude-capa-officer-skill.git ~/.claude/skills/capa-officer
```

On Windows, use `%USERPROFILE%\.claude\skills\capa-officer` as the destination.

## Usage

Claude Code can load the skill when a request matches its description. You can also invoke it directly with `/capa-officer`.
